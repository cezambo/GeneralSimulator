# panel-web

Painéis densos de dados, em React: inspetor de agente, seletor de modelo por tier, timeline, visualizador de trace e dashboard de custo.

**Ainda não começou.** Entra em V2 ([04-ROADMAP.md](../../docs/04-ROADMAP.md)), e a spec é [SPEC-U](../../docs/spec/SPEC-U-ui.md).

O pacote existe desde já para que o workspace tenha a forma final e ninguém precise reorganizar diretório depois — mover pacote mexe em caminho de import, de build e de configuração de editor ao mesmo tempo.

Verificação é por ferramenta de navegador: o agente navega, tira screenshot, clica, lê o console e inspeciona o DOM, sem instalar nada ([06-AMBIENTE.md](../../docs/06-AMBIENTE.md) seção 3).
